# Whack-a-mole!
[Ссылка](https://deploy-preview-83--js-30-widget-gallery.netlify.app/students/oardieldei/whack-a-mole/)

Игра сделана по заданию, плюс реализованы дополнительные возможности из списка. 

### База
- [x] Визуальное повторение демки с небольшими изменениями:
  - Очки отделил от заголовка и подписал, выглядит логчинее.
	- Кнопка теперь видна.
	- Немного обновил цветовое оформление.
- [x] Функционал аналогичный:
  - Запуск игры происходит по нажатию на кнопку.
	- Кроты вылазят из случайных норок на случайное время, нужно успеть их кликнуть.
	- За каждый клик дается по очку, сами очки отображаются в процессе игры.
	- Время ограничено, нужно успеть кликнуть как можно больше кротов!
### Обязательные улучшения
- [x] Добавлены уровни сложности:
	- Если за 10 секунд игрок успевает кликнуть 5 кротов, начинается следующий уровень.
	- Информация о переходе на новый уровень так же отображается справа от поля.
	- Сложность уровня определяется минимальным (`400 / currentLevel`) и максимальным (`2000 / currentLevel`) временем отображением крота.
- [x] Хранение лучшего результата (очки и уровень) в localStorage:
	- Реализовано.
	- Отображается на экране и хранится при перезагрузке страницы.
	- Улучшено в соответствии с одним из заданий следующего списка.
### Дополнительные улучшения
- [x] Звуковые эффекты:
	- Появление крота.
  - Попадание.
	- Переход на новый уровень.
	- Конец игры.
	- Иконка с возможностью заглушить звуки (в верхнем правом углу страницы).
- [x] Анимации:
  - Ease появление/исчезновение кротов.
	- Попадание (галочка).
	- `particle burst` - не очень понял, зачем это нужно, но реализовал при каждом клике.
- [x] Таблица лидеров:
	- Хранится топ-5 результатов.
	- Отображается в списке в левой части экрана.

# Custom media player!
[Ссылка](https://deploy-preview-83--js-30-widget-gallery.netlify.app/students/oardieldei/custom-video-player/)

Плеер сделан по заданию, также реализованы дополнительные возможности и нормальное цветовое оформление.

### База
- [x] Визуальное повторение демки с небольшими изменениями:
  - Добавлены новые функциональные кнопки.
	- Добавлены дополнительные возможности вне самого плеера.
- [x] Функционал (базовый):
	- Отображение плеера.
	- Полоса прогресса с соответствующим обработчиком действий мышью.
	- Кнопка воспроизведения.
	- Ползунок громкости.
	- Ползунок скорости.
	- Кнопки перемотки вперед/назад.
	- Кнопка фулскрина (в демке ее нет, но в задании есть).
### Обязательные улучшения
- [x] Горячие клавиши:
  - `Space` - воспроизведение/пауза.
	- `M` - выключить/включить звук.
	- `<` и `>` - уменьшение/увеличение скорости воспроизведения (работает в английской раскладке при зажатой клавише `Shift`).
	- `F` - включение/отключение режима "Во весь экран".
- [x] Горячие клавиши работают только в случае наведения курсора на плеер.

### Дополнительные улучшения
- [x] Дополнительные горячие клавиши:
  - `K` - воспроизведение/пауза.
	- `J` и `L` - перемотка назад/вперед на 10 секунд.
	- `Arrow left` и `Arrow right` - перемотка назад/вперед на 5 секунд.
	- `Arrow up` и `Arrow down` - увеличить/уменьшить громкость на 10%.
	- `0`..`9` - перемотать на процент длительности видео (0%..90%).
- [x] Перелючение между видео:
  - Добавлены кнопки переключения на следующее/предыдущее видео.
	- Список видео отображается под видео с подсветкой автивного и возможностью переключиться на другое.
	- Название видео в списке отображается при наведении курсора.
- [x] Мини каталог видео:
  - Каталог реализован при открытии сайта.
	- Клик по видео открывает плеер.
### Улучшения вне ТЗ
- [x] Кнопка "Назад":
  - Отображается при открытии плеера.
	- Дает возможность вернуться на главную страницу со списком видео.
- [x] Смена цветового оформления:
  - Реализовано по кнопке "Change Colors!"
	- Выбор пользователя хранится в localStorage.
	- Работает без перезагрузки страницы.
- [x] Индикатор скорости воспроизведения:
  - Отображает актуальную скорость.
	- По клику возвращает скорость к 1х.
- [x] Иконка громкости:
  - Отображает muted/unmuted состояние.
	- По клику включает/отключает состояние muted.
- [x] Перемотка вперед:
  - По аналогии с кнопкой перемотки назад перематывает на 10 секунд.
- [x] Полоса прогресса:
  - При наведении мыши увеличивается в размере для более удобного использования.
- [x] Длительность:
  - Отображается полная длительность видео и текущее время воспроизведения в формате `mm:ss`.
- [x] Превью:
  - При запуске плеера отображается превью видео.
