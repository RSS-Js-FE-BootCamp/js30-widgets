# 🎹 Virtual Music Kit

## 📖 Описание

**Virtual Music Kit** 

- Проект разработан с использованием чистого HTML, CSS и JavaScript без внешних библиотек.
- Кнопка переключения светлой и темной темы
- Ввод и воспроизведение последовательностей нот
- Тема сохраняется в localStorage
- Визуальный эффект при нажатии клавиш
- Приложение воспроизводит звуки при нажатии клавиш на клавиатурек и при клике мышью по    соответствующей клавише
- Переключение инструмента с ударной установке на пианино 
- Плавающие названия нот, которые появляются при клике
- При нажатии на клавишу появляется разноцветный круг
- Полноценное виртуальное пианино с октавами
